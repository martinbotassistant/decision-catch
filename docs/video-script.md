# Decision Catch — Demo Video

**Target length**: Under 4:30 minutes  
**Demo project**: PAY (Payment System)

## Video Structure

See [`demo-data.md`](./demo-data.md) for the complete walkthrough script with sample issues.

### Recommended flow (4 minutes):

1. **Problem intro** (30s)
   - Show a Jira comment with a decision
   - Show another issue that contradicts it
   - "This happens all the time, and nobody catches it"

2. **Solution demo** (2m 30s)
   - Open PAY-1, show 3 candidate decisions in panel
   - Approve all three with one click each
   - Open PAY-5, show drift warning with explanation
   - Resolve drift with note
   - Show it moved to Resolved section

3. **More examples** (30s)
   - Quick cuts showing PAY-6 and PAY-7 drift warnings
   - Emphasize automatic detection

4. **Rovo bonus** (30s) *[Optional]*
   - Ask "check drift in PAY-6" in Rovo chat
   - Show response with drift details

5. **Closing** (30s)
   - Recap: automatic catch, drift warnings, resolution workflow
   - "Never lose another decision in a comment thread"

## Key Messages

- ✅ **Automatic** — no manual entry, finds decisions in existing comments
- ✅ **Smart** — understands contradictions, not just keywords
- ✅ **Actionable** — warns before contradicting work ships
- ✅ **Zero setup** — no APIs, no config, just install and go

## What NOT to mention

- ❌ Don't claim "100% accuracy" (heuristic-based by design)
- ❌ Don't mention real company names
- ❌ Don't oversell future features (LLMs, Confluence, etc.)
